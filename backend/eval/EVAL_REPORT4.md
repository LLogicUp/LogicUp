> 평가 일시: 2026-05-26
> 모델: `openai/gpt-oss-120b` (via Groq) ← 3차(8B)에서 원복
> 테스트 케이스: 11개 문제 × 최대 3레벨 = 총 26개 케이스 (에러 1건 제외 시 유효 25건)

> **평가 기준 수정**: 레벨 1에서 오류가 있는 줄 코드(스니펫) 제시는 허용, 수정 방법/정답 코드만 금지

**핵심 결론:**

- **카테고리 분류 F1 최고치 달성**: 0.515 → **0.653** (+0.138) — SYSTEM_PROMPT 지시 12(근본 원인 우선) 효과로 알고리즘 케이스 분류 정확도 향상
- **규칙 위반 재판정 6건**: L1에서 오류 줄 코드 스니펫 제시는 허용(학습에 도움)으로 기준 변경 → 실제 위반은 "정답/수정 코드 노출"로 한정
- **L2 정답 코드 노출 지속**: 예시 코드를 "올바른 예/잘못된 예"로 제공하며 사실상 정답을 노출 — 레벨 규칙을 프롬프트에서 더 강하게 제한 필요
- **c_memory_leak 한계**: `error_log` 없이는 LLM이 "코드에 오류가 없습니다"로 응답 — 테스트 케이스에 valgrind 로그 추가 필요
- **py_index_error 한계**: LLM이 `배열 범위 초과`(C 용어)를 고집 — `리스트 인덱스 오류 (IndexError)` 또는 `배열 범위 초과` 모두 정답으로 허용하거나 expected_categories 수정 필요
