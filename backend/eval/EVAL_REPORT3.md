# LogicUp 힌트 정확도 평가 보고서 (3차)

> 평가 일시: 2026-05-25
> 모델: `llama-3.1-8b-instant` (via Groq) ← 2차와 모델 변경
> 테스트 케이스: 11개 문제 × 최대 3레벨 = 총 25개 케이스 (에러 1건 제외 시 유효 24건)
> 평가 방식: **카테고리 분류 정확도** (Precision/Recall/F1) + **LLM-as-Judge 품질 평가**
> 변경사항: SYSTEM_PROMPT에 "근본 원인 카테고리 우선 선택" 지시 추가 + 모델 교체

**핵심 결론:**
- **카테고리 분류 F1 급락**: 0.515 → **0.101** — 8B 모델이 허용 목록 외 카테고리를 자주 사용 (`형식 오류 (printf/scanf)`, `무한 루프`, `데이터 타입 불일치` 등 비표준 이름)
- **규칙 위반 증가**: 4건 → **9건** — 작은 모델일수록 지시 준수율 낮음
- **Judge 품질은 준수**: 4.25/5 — 힌트 내용 자체는 나쁘지 않으나 형식 미준수
- **`%c` 제약조건은 유지**: 2차에 추가한 SYSTEM_PROMPT 효과 지속
